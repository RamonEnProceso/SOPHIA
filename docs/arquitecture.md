# Arquitectura

## Versión actual: v0.0.2

## Estructura de carpetas

```
 /SOPHIA
    ├── backend/
    │   └── app/
    │       ├── ai/
    │       ├── models/
    │       ├── routers/
    │       └── services/ 
    ├── docs/
    │   └── assets/
    ├── init/
```

## Stack actual
- FastAPI + Python
- Ollama + Qwen 3.5
- PostgreSQL
- Docker
